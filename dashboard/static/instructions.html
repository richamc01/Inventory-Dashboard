How to use the Hardware Inventory workbook

Everything you need to keep Hardware Inventory.xlsx up to date, one task at a time. Each task lists the tab, the exact cells, and what to check afterwards.

Ground rules

  • Never type in a formula column. On the Sales and Listings tabs those have grey headers. On the Computers tab, columns U to Y are formulas too, even though their headers are blue.
  • One row = one thing. One machine, one RAM module, one bin, one sale, one listing.
  • Asset IDs never change and are never reused, even for a scrapped or sold machine.
  • To remove values, select the cells and press Delete. Don't use right-click > Delete (that removes whole rows and shifts the formulas).
  • When you paste into the workbook, paste values (Ctrl+Alt+V, then V, then Enter). A normal paste brings in the source's formatting and wipes the grey sold-row shading.
  • Save and close Excel when you're done. The dashboard reads the saved file, and Nextcloud syncs it to the server.

Type codes

Every asset ID starts with a type code, then a dash and three digits, for example DT-007. RAM has no label; its own barcode (serial) is its ID.

Hover over a type code anywhere on the dashboard (a Type column, a Type chart, a detail panel) to see what it stands for. The codes and their meanings are kept on the workbook's Lists tab, columns J to L (Type code, Meaning, Used for). To add or reword one, edit it there; the dashboard follows after you save.

Add scanned computers (Computers tab)

When: after running inv.sh on one or more machines. Scanner: must be on Enter (see Scanner Tab/Enter).

First import

  1. Plug the INVENTORY USB stick into this PC.
  2. In File Explorer, open the INVENTORY stick and double-click inventory.csv. It opens in Excel.
  3. In inventory.csv, click cell A2 (the first row under the header).
  4. Press Ctrl+Shift+End. This selects from A2 to the last used cell (column T of the last row).
  5. Press Ctrl+C.
  6. Switch to Hardware Inventory.xlsx and click the Computers tab at the bottom.
  7. Click cell A2.
  8. Paste values: press Ctrl+Alt+V, press V (Values), press Enter.
    Or with the mouse: Home tab > the arrow under Paste > under Paste Values, click the first icon (Values).
  9. Check: the last pasted column is T (detail_file), and columns U to Y still show their results.
  10. Close inventory.csv without saving.
Why paste values? A normal paste (Ctrl+V) also copies the CSV's plain formatting over the grey "sold" shading on A to T. Paste Values keeps the shading. If you do use Ctrl+V by habit, nothing else breaks; the Data tab's Workbook health will tell you the shading rule now covers fewer cells.

Refresh after more scans

  1. On the Computers tab, click the box left of the formula bar (the Name Box), type A2:T500, press Enter.
  2. Press Delete. This clears only the pasted scan data; columns U to Y are not touched.
  3. Repeat the first import steps 2 to 10 with the full inventory.csv (it holds every scan, old and new).

What columns U to Y do (formulas, even though the headers are blue: don't type in them)

V manual_notes

W win11_effective

X ram_mb_effective

Y sold

Scan files

The dashboard shows each machine's full scan from the inventory-raw folder next to the workbook. Keep each scan .txt file there with its original name (it starts with the asset ID, for example DT-007_ABC1234.txt). A re-scan adds a second file; the dashboard lists both.

Record problems and overrides (Master tab)

Use it for: machines that never reach the scan, Windows 11 overrides, and notes about any machine. A machine can be on both Master and Computers; that's normal.

  1. Click the Master tab, then the first empty cell in column A.
  2. A Asset ID: scan the label or type it.
  3. B Service Tag, C Model, D Type, F Date: optional. No formula uses them.
  4. E Status code: pick from the drop-down if the machine has a problem (table below). Leave blank or OK otherwise.
  5. G Win11 override: pick a code only if you checked the BIOS (table below).
  6. H Notes: anything worth knowing. These show on the Computers tab (column V) and in the dashboard.
Borrowed RAM: if a machine was scanned with a test DIMM that you then removed, write TEST DIMM USED, real RAM = none in column H. The Computers tab then counts its RAM as 0.

Add labeled items and RAM (Items tab)

Scanner: set it to Tab before you start, and back to Enter when you finish (see Scanner Tab/Enter). Full per-item details are in Other Hardware Inventory Method.md.

Labeled items (MON, NW, UPS, PSU, MB, CH, MS): one row per item

  1. Click the first empty cell in column A. Scan the asset label. The cursor moves to B.
  2. Scan the manufacturer's serial barcode. The cursor moves to C. No serial: press Tab, and later type NO SERIAL in column H.
  3. C Type (drop-down), Tab. D Make, Tab. E Model, Tab.
  4. F Key spec, Tab. Monitor: screen size. Switch: port count. UPS: VA rating. PSU: wattage. Motherboard: socket. Chassis: height.
  5. G Condition (drop-down: Working, Untested, Faulty), Tab. H Notes.
  6. Press Enter. Excel returns to column A of the next row.

RAM: one row per module

RAM has no asset label. Column A stays empty, and the module's own barcode in column B is its ID.

  1. Sort the modules into piles of identical part numbers. Count one pile.
  2. In the first empty row, fill C to H once: C RAM, D make, E part number, F form factor, size and speed code (for example DIMM 8GB PC4-2400T), G Untested.
  3. Select column B from that row down to the pile's last row (first row + count − 1). Scan each module. The cursor moves down inside the selection.
    Don't scan past the last cell: it wraps to the top and overwrites it.
  4. Select columns C to H for the pile's rows and press Ctrl+D to copy the details down.
  5. Check: every value in column B is different.
Write the Key spec the same way every time (for example DIMM 8GB PC3L-12800U 2Rx8). The dashboard reads size, generation (DDR3, DDR3L, DDR4), form factor and ECC from it.

Add bulk bins (Bulk tab)

For cables, keyboards and power bricks. One row per bin. Scanner: Tab.

  1. Click the first empty cell in column A. Scan the BIN label. The cursor moves to B.
  2. B Item type (drop-down), Tab.
  3. C Spec, for example DisplayPort to DisplayPort, 6 ft or Dell 130W 19.5V barrel, Tab.
  4. D Quantity (whole number), Tab. E Condition (drop-down).
  5. Press Enter.
Never mix power bricks with different wattage, voltage or connector in one bin.

Scanner: switch between Tab and Enter

The Tera HW0002 scanner sends a key after each barcode. Enter for computer scans (inv.sh). Tab for the Items and Bulk tabs. Change it only twice: to Tab before Items/Bulk work, back to Enter when done.

  1. Open the Tera HW0002 manual to the page titled Terminators (page 10). It has five barcodes in a row.
  2. For Tab: scan the fourth barcode, Add Horizontal Tab<HT> (0x09).
  3. For Enter: scan the first barcode, Add Carriage Return<CR> (0x0D)*.
  4. Test in Notepad: scan any barcode. Enter moves the cursor to a new line. Tab jumps it right.
  5. If it acts strangely: scan Reset to Wireless Factory Defaults (manual page 01, first barcode). That returns it to Enter. Don't scan other setup barcodes.

List something for sale (Listings tab)

One row per machine or item, even when one Facebook post covers 12 machines (give all 12 rows the same price and date). Leave a row on this tab forever: when the thing sells, it turns Sold by itself.

Add a listing

  1. Click the Listings tab, then the first empty cell in column A.
  2. A Asset ID: scan the label or pick from the drop-down. For RAM, scan the module's serial. Hardware IDs (like MON-001) are accepted after a warning; click Yes.
  3. B Listing status: pick from the drop-down (table below).
  4. C Asking price: the price for this one unit, as a number.
  5. D Date listed: type it as 2026-11-09 or 11/9/2026.
  6. E Platform: pick from the drop-down.
  7. F Listing URL and G Notes: optional. A link starting with https:// becomes clickable in the dashboard.
  8. H Current status fills in by itself. Don't type in it.

Common changes

Price drop
Type the new price over column C. Only the current price is kept.
Buyer lined up
Change column B to Pending.
Sale fell through
Change column B back to Listed.
It sold
Record the sale on the Sales tab (next section). Leave the Listings row alone: column H changes to Sold and the row turns grey. It then counts once, at its actual sale net, never at its asking price.
Relisted later
Update B, C and D on the same row. Don't add a second row; a second row for the same ID is ignored and flagged.
Net sales potential = net of everything sold + asking prices of everything Listed or Pending. Total profit potential = net sales potential − the lot price. No fees or shipping are taken off asking prices.

Record a sale (Sales tab)

Every row is one thing sold. Type only in the blue columns. The grey columns (D, E, Q to X) fill in by themselves.

One machine or item

  1. Click the first empty cell in column A. A Sale date: type 2026-11-07 or 11/7/2026.
  2. B Asset ID: scan the label or pick from the drop-down. For RAM, scan its serial. Other IDs (like MON-001, or a Master-only machine) are accepted after a warning; click Yes.
  3. C Order ID: leave blank.
  4. F Sale price: what the buyer paid. G Fees and H Shipping cost: leave blank if none. Leave I, J, K blank.
  5. L Platform and M Payment method: from the drop-downs. N Buyer: optional. O Sold with: what went with it (RAM, drive, OS, power cord). P Notes.
  6. Check: column X Check says OK.

Several things to one buyer (an order)

  1. Pick a new order ID, for example ORD-007. Never reuse one.
  2. Add one row per machine. Type the same order ID in column C on every row.
  3. On the order's first row only: A Sale date, I Order total (what the buyer paid for all of them), J Order fees, K Order shipping, L Platform, M Payment method, N Buyer. The other rows use the first row's date and platform.
  4. Leave F Sale price blank on every row to split the total evenly. To set your own split, type a price on some rows; the rest is split evenly over the blank ones.
  5. Leave G and H blank on order rows. Order fees and shipping are split evenly.
  6. Check: column X Check says OK on every row of the order.
After saving, the machine shows SOLD on the Computers tab (column Y), its rows on Computers, Items and Listings turn grey, and the dashboard counts it as sold.

Lot price and totals (Selling Dashboard and Summary tabs)

  1. Type what you paid for the whole lot once, in the yellow cell B3 on the Selling Dashboard tab.
  2. Everything else on Selling Dashboard and Summary is calculated. Don't type in them.

Selling Dashboard shows units sold, gross, fees, shipping, net, averages, lot cost recovered, profit, and breakdowns by type, platform and month. Summary shows counts of computers by type, Windows 11 results, scan status, items, bulk units and Master rows. The dashboard's Data tab checks its own totals against Selling Dashboard.

Change a drop-down (Lists tab)

Each drop-down reads a fixed range of the Lists tab. For example, Sales > Platform reads Lists!F2:F7.

Rename a value
Type over it on the Lists tab. Rows that already use the old wording keep it; change those by hand.
Add a value
A value typed below the end of the range won't appear in the drop-down. Either type over an unused value inside the range (like Other), or widen the range: select the column on the tab that uses it, then Data tab > Data Validation > change Source > OK.
After widening a range
The dashboard's Workbook health will report the drop-down "has changed". That's expected: ask Claude to update the reference copy.

Saving

  1. Save in Excel (Ctrl+S) and close it.
  2. Nextcloud syncs the file to the server. Give it a few seconds.
  3. The dashboard checks every minute and reloads by itself. Click Refresh (top right) to load it right away. The time next to "Workbook saved" at the top shows which save you're looking at.
Before a big change, make a copy of the file in the same folder, for example Hardware Inventory (backup 2026-11-10).xlsx.

Fixing Workbook health problems (Data tab)

Workbook health compares the file with a reference copy of its formulas, drop-downs and shading rules. Each problem line names the tab, the column and the rows.

No formula in row(s) …
Select a cell in that column that still has the formula, Ctrl+C, select the broken rows in the same column, Ctrl+V. Save.
Formula differs from the rest of the column
Same fix. If you changed it on purpose, ask Claude to update the reference copy.
No formula in B4 (Summary or Selling Dashboard)
Something was typed over a calculated cell. Copy that cell from the backup file, or undo (Ctrl+Z) if Excel is still open.
Drop-down … is missing
Usually the file was saved by something other than Excel, or cells were pasted over. Restore from the backup, or ask Claude to put the drop-down back.
Shading rule now covers …
A normal paste cut the grey sold-row rule. Home > Conditional Formatting > Manage Rules > Show formatting rules for: This Worksheet > edit Applies to back to the range shown (for example =$A$2:$Y$500).
Column header is …
A column was renamed, moved or deleted. Undo it, or restore from the backup.
